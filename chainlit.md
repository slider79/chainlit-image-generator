# Mirage

Describe something and it will be drawn, using
[Pollinations AI](https://pollinations.ai): free, open source, no API key.

Use the **settings panel** to change the image size or style. Every result comes
with buttons to generate it again or make a variation, each of which re-rolls
the seed for a different take on the same prompt.

Large images can take up to a minute.

Built with [Chainlit](https://docs.chainlit.io).
